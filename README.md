A new and optimized generation of proxies using GitHub Codespaces. The project is based on Xray core and the redesigned WebSocket protocol, aiming to provide stable, fast, and fully automated connectivity.

---
## Fork for individual use

**---> Once forked go to code section, enter codespace tab and hit create on main.
Wait for the project to get fully built then you'll receive your configeration links in the terminal to import on a v2ray client !!**

## Please do
Go to [github.com/settings/codespaces](https://github.com/settings/codespaces) find "Default idle timeout" and set it to max (240 mins) this matters because codespace goes inactive if you close/leave its tab open for some time hence this can get irritating visiting it every once in a while to make it run indefinitely.
* You can also change region on the same page; those nearer to your area are considered more reliable.
* It is advised to merge your configerations with Psiphon for more stability & better connection.
* **Pro tip :** When you're not using the proxy, stop the server from [the admin panel](https://github.com/codespaces) to avoid unnecessary quota usage.
---
> Only limit you should be aware of : Normal github account codespace usage quotas are bound to 60 hours per month for 2-core machines & 90 hours for accounts with student developer packs. When it runs out, your codespace kinda dies... Make a new account! ;)
